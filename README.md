# Birthday-site 🎂✨

A single-page animated birthday celebration website — a sweet, shareable greeting page for someone special, built entirely in one self-contained HTML file (no build step, no dependencies).

## Features

- Animated gradient background with a sparkling color-shift effect
- Big celebratory birthday message with emoji flair
- Fully responsive — looks good on phones and desktops
- Zero dependencies: one HTML file with inline CSS, ready to host anywhere

## Tech stack

- **HTML5** + **CSS3** (animations, gradients)
- No frameworks, no build tools

## Project structure

```
index.html      # the entire site (single file)
README.md       # this file
LICENSE         # license
```

## Quick start

Just open the page in a browser — no build, no server needed:

```bash
# Option 1: open directly
open index.html

# Option 2: serve locally
npx serve .
```

To personalize it, edit `index.html` directly: change the name/title in the
`<title>` tag and the message text in the body.

## Deploy notes

Static single file — deploy as-is to GitHub Pages, Netlify, or Cloudflare
Pages. GitHub Pages is enabled on the `main` branch (root path).
